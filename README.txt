НОВОГОДНЕЕ КОЛЕСО УДАЧИ — сайт мероприятия

Запуск:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для разработки можно открыть папку в VS Code и запустить через Live Server.

Файлы:
- index.html — структура сайта
- style.css — оформление и адаптивность
- script.js — анимации и логика колеса фортуны
- assets/event-poster.png — исходный постер

Колесо:
- добавление и удаление участников прямо на странице
- автоматическое построение секторов по списку участников
- случайный выбор победителя, анимация вращения и окно результата
- одинаковые имена не добавляются повторно

Важно:
Колесо работает только на стороне браузера. Результаты не сохраняются на сервере и не подходят для подтверждения официальных призов без серверной проверки.
Перед публикацией проверьте год, даты, условия и добавьте ссылку на Discord.
